Chức năng

  • R1. Trích xuất theo nguồn đang dẫn (mở rộng):

    • R1c GMaps: maneuver + cự-ly (notification + a11y — đã có); B3-capture là phụ.
  • R2. Menu chọn nguồn dẫn đường — UI chọn AUTO / GMaps / Waze / VietMap → Prefs.setSourceMode → SourceArbiter tôn trọng; hiển thị nguồn đang active. (Data + arbiter có sẵn; chỉ thêm UI.)
  • R3. Bắn ra CỤM + HUD — SONG SONG 2 usecase (KHÔNG fallback):
    • (a) Payload gốc (BydHal): đẩy mũi tên + cự-ly + làn + camera vào payload cụm-centre + HUD — CỨ BẮN đủ field; HUD/cụm nào hỗ trợ thì lên, không hỗ trợ thì kệ (bắn thừa vô hại, KHÔNG gate — kể cả tên-đường HUD).
    • (b) Overlay cụm tự vẽ (display-1): vẽ làn + camera bằng view riêng, độc lập với (a).
    • Cả (a) và (b) chạy SONG SONG (2 đầu ra khác nhau) — KHÔNG phải cái này fallback cái kia.
  • R4. Làn — đọc ĐỦ mũi tên TỪNG LÀN + render: mỗi làn đọc hướng (trái / thẳng / phải / kết hợp) + trạng thái RECOMMENDED (sáng) vs không (mờ). VD 4 làn khi map bảo đi thẳng: [L1 trái=mờ · L2+L3 thẳng=sáng · L4 phải=mờ]. Overlay vẽ ĐỦ các làn theo thứ tự + tô sáng làn recommended.
  • R5. Camera → cụm + HUD + overlay: (a) đẩy camera (icon + cự-ly) vào payload cụm/HUD (cứ bắn, như R3a); (b) overlay cụm vẽ icon camera + cự-ly BÊN PHẢI speed sign.
  • R6. Overlay layout (display-1, reuse SpeedBadgeOverlay): dải làn vẽ Ở DƯỚI overlay speed-badge; camera bên phải speed sign. Cùng cơ chế TYPE_APPLICATION_OVERLAY display-1, không dựng overlay mới.

4.3 Quyết định thiết kế

  • Làn: học OpenBYD — a11y tìm *:id/laneGuidanceView (Waze) / view tương ứng VietMap → bounds → capture → LaneSignature (thuần) phân tích dải làn (mỗi làn: có/không, hướng mũi tên, recommended). Fallback: nếu app phơi làn qua content-desc/text thì đọc thẳng (rẻ hơn ảnh).
  • Output owner (T7): 1 owner đọc ScreenCaptureSignal (+ nav notification hiện có) theo SourceArbiter, đẩy: mũi-tên/cự-ly → BydHal (HUD+cụm-centre, đã chạy); làn → cụm (register hoặc overlay); camera → overlay badge. Có keep-alive + clear khi hết dẫn (như HudKeepAlivePolicy đã có).
  • Overlay cụm: TÁI DÙNG cơ chế SpeedBadgeOverlay/ClusterSpeedBadgePort (TYPE_APPLICATION_OVERLAY display-1) — thêm view nav (mũi tên/làn/camera) cạnh badge tốc-độ, KHÔNG dựng cơ chế overlay mới.
  • Menu nguồn: item trong MainActivity (như selector chế-độ-hiển-thị cụm đã có) set Prefs.sourceMode; hiển thị SourceArbiter.activeSource.
  • Cụm register làn vs overlay: thử register gốc 0x19802058… trước (cụm tự vẽ làn đẹp hơn); nếu không provision → overlay tự vẽ. (OQ3, verify on-car.)
  • Context7: chỉ dùng Android SDK (AccessibilityWindowInfo/MediaProjection/WindowManager) + BYDAuto HAL + khối nội bộ đã có → không có thư viện mới → Context7 n/a.
