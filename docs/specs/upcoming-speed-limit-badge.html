3. Requirements

Chức năng

  • R1. Khi VietMap báo giới hạn tốc độ sắp tới (upcomingLimitKph ≠ null, alertFullFreshness=FRESH) và cự ly upcomingDistanceMeters ≤ ngưỡng → hiện trên cụm một biển giới hạn tốc độ (giá trị SẮP TỚI) + cự ly tới nó (vd "300 m").
  • R2. Cự ly đếm lùi theo mỗi snapshot khi lại gần; khi tới nơi (VietMap chuyển giá trị đó thành giới hạn HIỆN TẠI speedLimitKph) → ẩn biển sắp-tới.
  • R3. Ẩn khi: upcomingLimitKph=null, hoặc alertFullFreshness≠FRESH (stale/unavailable), hoặc cự ly > ngưỡng, hoặc master Nav+HUD/Cast tắt.
  • R4. Phân biệt rõ với biển giới hạn HIỆN TẠI (badge đang có): biển sắp-tới nhỏ hơn / có nhãn cự ly bên dưới → tài xế không nhầm "đang phạt" với "sắp tới".
  • R5. Toggle bật/tắt riêng (mặc định BẬT — theo tiền lệ badge). Off → không bao giờ vẽ biển sắp-tới.

Phi chức năng

  • R6. Không ảnh hưởng badge giới hạn HIỆN TẠI (thêm mới, không sửa hành vi cũ). Degrade-safe: thiếu data → chỉ ẩn, không crash, không đụng feed cụm.
  • R7. Quyết định hiện/ẩn + giá trị hiển thị là hàm thuần ở :core (unit-test off-car), không phụ thuộc Android.
  • R8. Off-thread, không chặn thread widget; tái dùng vòng đời overlay đã có (idempotent init + DisplayListener).

4. Design

4.1 Luồng dữ liệu (tái dùng pipeline hiện có)

  • speedLimitPusher (đã nhận VietMapWidgetSnapshot) tính thêm UpcomingBadgeDecision.decide(snapshot, thresholdM, System…) → đẩy xuống overlay qua 1 method mới setUpcoming(limitKph:Int?, distanceMeters:Int?) (null = ẩn).
  • Badge giới hạn hiện tại vẫn đi đường cũ (onSpeedLimit) — không đổi.

4.2 Hiển thị

  • Biển sắp-tới = 1 SpeedBadgeView thứ hai (tái dùng nguyên) hiển thị upcomingLimitKph, kích thước ~70% badge chính; nhãn cự ly (TextView/Canvas text) ngay dưới ("300 m" / dùng upcomingDistanceText nếu có, else format từ mét).
  • Vị trí (đề xuất): neo tương đối NGAY DƯỚI badge chính (badge chính đã có toạ độ user đặt qua UI placement) → không cần UI đặt vị trí thứ hai. Container overlay bọc [badge chính] + [biển sắp-tới + cự ly] theo trục dọc.
  • Đếm lùi: mỗi snapshot cập nhật nhãn cự ly; R2/R3 quyết ẩn.

4.3 Quyết định thuần (:core)

data class UpcomingBadge(val show: Boolean, val limitKph: Int, val distanceMeters: Int)
object UpcomingBadgeDecision {
  // show khi: limit hợp lệ (>0) + FRESH + 0 < dist ≤ threshold. Ngoài ra ẩn.
  fun decide(limitKph: Int?, distanceMeters: Int?, fresh: Boolean, thresholdM: Int): UpcomingBadge
}
  • Unit-test: null→ẩn; stale→ẩn; dist>threshold→ẩn; dist trong ngưỡng + FRESH→hiện; dist≤0→ẩn (đã tới).

4.4 Prefs

  • showUpcomingBadge (Bool, mặc định true) — R5 toggle.
  • upcomingThresholdMeters (Int, mặc định 1000) — ngưỡng bắt đầu hiện (OQ: có cho chỉnh trong UI không).
